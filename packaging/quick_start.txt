Market Brief · 미국 증시 뉴스 위젯
Windows 10/11 64비트용 · 버전 {version}

처음 실행하기
1. ZIP 파일을 마우스 오른쪽 버튼으로 누르고 [모두 압축 풀기]를 선택합니다.
2. 바탕 화면이나 문서 폴더처럼 파일을 저장할 수 있는 위치에 풉니다.
3. 압축을 푼 폴더 안의 MarketBrief.exe를 더블클릭합니다.
4. 잠시 기다리면 브라우저에 통합 위젯이 자동으로 열립니다.
   Python 설치, 명령어 입력, 관리자 권한은 필요 없습니다. 인터넷 연결은 필요합니다.

화면 사용하기
- 브라우저 창의 폭을 줄여 작은 위젯처럼 사용할 수 있습니다.
- 오른쪽 위 [설정]에서 뉴스 표시 개수(최대 30개), 시간대, 테마를 바꿉니다.
- 뉴스 제목을 누르면 한국어 발췌 번역을 읽고 원문·한국어판 링크를 선택할 수 있습니다.
- 창을 잃어버렸으면 Market Brief 실행 창의 [위젯 열기]를 누릅니다.
- 종료하려면 Market Brief 실행 창의 [종료]를 누르거나 그 창을 닫습니다.
  브라우저 탭만 닫으면 뉴스 수집은 계속됩니다.

API 키 파일
keys/massive_api_key.txt : Massive의 Benzinga News API 키 한 줄
keys/deepl_api_key.txt   : DeepL API 키 한 줄

키가 이미 들어 있으면 수정하지 않고 바로 실행하면 됩니다.
키를 바꿀 때는 위젯을 종료하고 해당 TXT 파일을 메모장으로 열어 새 키 한 줄만 저장합니다.
키가 들어 있는 배포본은 같은 계정의 사용량을 소모하므로 지정한 받는 분에게만 전달하세요.
여러 컴퓨터에서 동시에 실행하면 뉴스·번역 사용량도 각각 발생합니다.

폴더 안내
- MarketBrief.exe : 실행 파일
- _internal      : 실행에 필요한 파일입니다. 삭제하거나 따로 옮기지 마세요.
- keys           : API 키 TXT 파일
- data / logs    : 실행 후 자동 생성되는 뉴스·번역 저장 파일과 진단 기록

실행이 안 될 때
- ZIP 안에서 바로 실행하지 말고 먼저 전체 압축을 풀어 주세요.
- MarketBrief.exe만 꺼내지 말고 폴더 전체를 같이 옮겨 주세요.
- 처음 받은 서명 없는 프로그램으로 Windows 확인 화면이 나올 수 있습니다.
  보낸 사람과 파일 출처를 확인한 경우에만 실행을 진행하세요.
- API 인증이나 한도 문제는 위젯 상단 상태에 표시됩니다. 키를 확인한 뒤 다시 실행하세요.
- '연결 주소를 사용 중'이라고 나오면 이미 실행 중인 Market Brief 창을 확인하세요.
- 문제가 계속되면 logs 폴더의 기록을 보낸 사람에게 알려 주세요. API 키 파일은 공개하지 마세요.
