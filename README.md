# 미국 증시 뉴스 위젯

현재 버전: **v1.8.0 — Windows 실행 파일 배포**. 버전별 변경 사항은 [CHANGELOG.md](CHANGELOG.md)에 기록합니다.

방송 진행자가 별도 로컬 화면에서 미국 증시 관련 뉴스를 확인하는 위젯입니다. **Massive의 Benzinga News REST API**를 주력으로 사용하고 연준·BLS·BEA·SEC·EIA 공식 발표, CNBC·PR Newswire RSS를 함께 모읍니다. Marketaux와 Benzinga 직접 스트림도 선택적으로 지원합니다. 한국어 제목은 DeepL로 번역합니다. 현재 사용 범위는 시청자에게 송출하지 않는 진행자 전용 열람입니다.

## Windows 실행 파일로 사용

Windows 10/11 64비트용 ZIP의 **전체 압축을 푼 뒤 `MarketBrief.exe`를 더블클릭**합니다. Python 설치나 명령어 입력 없이 기본 브라우저에 `?view=widget&tab=combined` 화면이 자동으로 열립니다. 실행 창의 **위젯 열기**로 화면을 다시 열고 **종료** 또는 창 닫기로 뉴스 수집을 끝냅니다. 브라우저 탭만 닫으면 수집은 계속됩니다.

API 키는 EXE 옆 `keys/massive_api_key.txt`, `keys/deepl_api_key.txt`에서 자동으로 읽습니다. 키를 포함해 개별 전달받은 ZIP은 바로 실행하면 됩니다. 공개 GitHub 빌드에는 빈 TXT 파일만 들어 있으므로 키를 한 줄씩 저장한 뒤 실행해야 합니다. 메모장의 UTF-8·UTF-8 BOM·UTF-16을 지원합니다. 키를 포함한 파일은 공개 저장소·릴리스에 올리지 않습니다.

`_internal` 폴더는 Python·Tcl/Tk·앱 파일을 포함하므로 EXE와 같이 유지합니다. 뉴스·번역 캐시와 진단 로그는 EXE 옆 `data`, `logs`에 저장됩니다. 바탕 화면·문서처럼 쓰기 가능한 위치에 압축을 풀어야 하며 인터넷 연결이 필요합니다. 중복 실행은 추가 수집기를 만들지 않고 기존 위젯을 엽니다. 실행 창이 강제로 종료돼도 백그라운드 수집기가 남지 않도록 부모 프로세스를 감시합니다.

### Windows 배포본 빌드

[PyInstaller](https://pyinstaller.org/en/stable/operating-mode.html)는 대상 OS에서 빌드해야 합니다. Windows Python 환경에서 다음을 실행하거나 `.github/workflows/windows-portable.yml`을 사용합니다.

```powershell
python -m pip install -r packaging/requirements-build.txt
python packaging/build_windows.py
python packaging/smoke_windows.py
```

빌드 결과는 `dist/MarketBrief-v<버전>-Windows-x64.zip`이며 개인 키·뉴스 캐시·로그를 포함하지 않습니다. 자동 검증은 EXE를 한글·공백 경로로 옮기고 Python을 PATH에서 제외한 상태에서 시작·종료, 자식 프로세스 정리, 중복 실행 방지, 키 파일 HTTP 차단과 실제 GUI 창 닫기를 확인합니다. 유료 뉴스·번역 서비스에는 요청하지 않습니다. Windows Actions 빌드는 키가 없는 ZIP과 검증 결과만 빌드용 사전 릴리스에 게시합니다.

승인받은 키를 포함한 전달본은 공개 빌드를 내려받은 후 **로컬에서만** 만듭니다. 출력 파일은 Git에서 제외됩니다.

```bash
python3 packaging/prepare_delivery.py --archive dist/MarketBrief-v1.8.0-Windows-x64.zip --keys keys --output delivery/MarketBrief-v1.8.0-Windows-x64-private.zip
```

## 소스에서 실행

Python 3.10 이상을 사용합니다. 다음 파일에 키 한 줄을 넣습니다. 공식 RSS는 키가 필요 없습니다.

```text
keys/massive_api_key.txt
keys/deepl_api_key.txt
```

```bash
./run_massive.sh
# 같은 실행:
python3 tools/run_overlay.py --no-marketaux --no-reuters-default-feed --limit 30
```

브라우저에서 `http://127.0.0.1:8787/`를 엽니다. 편집·핀 고정: `http://127.0.0.1:8787/?edit=1`. 종료: Ctrl+C. 위 실행 예시는 탭별 최신 뉴스 30개를 준비합니다. 화면에 표시할 개수는 **설정 → 뉴스 표시 개수**에서 위젯·패널별로 1~30개를 선택합니다. OBS 브라우저 소스로도 동작하지만 현재 사용자가 요청한 용도는 별도 화면 열람입니다.

### 화면 크기와 읽기 도구

| 화면 | 주소 | 표시 |
|---|---|---|
| 작은 위젯 | `http://127.0.0.1:8787/?view=widget&tab=benzinga` | 최대 360px 폭, 기본 5개·설정에서 최대 30개, 목록 내부 스크롤 |
| 세로 패널 | `http://127.0.0.1:8787/?view=panel&tab=benzinga` | 최대 520px 폭, 위 실행 기준 기본 30개·개별 설정 가능, 목록 내부 스크롤 |

오른쪽 위 **위젯 / 패널**로 전환합니다. 기본은 세로 패널이며, 명시한 URL의 `view`가 저장된 선택보다 우선합니다. `limit`을 명시하면 두 모드 모두 해당 표시 개수를 사용하되 최대 30개로 제한합니다. 설정창에서 개수를 변경하면 URL의 `limit`을 제거하고 선택을 저장합니다. 작은 창에서는 폭과 높이가 자동으로 줄어듭니다.

- **뉴스·종목 검색:** 현재 받은 피드에서 한국어·영문 제목, 출처, 종목 코드로 찾습니다.
- **가＋ / 가－:** 글자 크기를 바꾸고 선택을 저장합니다.
- **읽기 고정:** 목록만 고정합니다. 스크롤해 내려갈 때도 자동으로 고정하여 새 뉴스 때문에 읽던 위치가 바뀌지 않도록 합니다. 수집과 연결 상태 확인은 계속되며, '새 뉴스' 또는 '최신 뉴스로 돌아가기'를 누르면 최신 목록을 표시합니다.
- **고정:** 카드에 마우스를 올리거나 키보드로 접근하면 개별 고정 버튼이 나타납니다. 터치 화면에는 항상 표시합니다. 핀 관리에서 한꺼번에 해제할 수 있습니다.
- **최근 5분:** 실제 발행 시각을 기준으로 표시합니다. 시간에 마우스를 올리면 선택한 두 시간대의 발행 시각을 확인할 수 있습니다.

### 표시 개수·시간대·테마 설정

오른쪽 위 **설정**에서 뉴스 표시 개수, 시계 시간대와 화면 색상을 변경합니다. 뉴스 분류·예상 영향·번역 검사는 위젯·패널 양쪽에 공통 적용됩니다.

- **뉴스 표시 개수:** 작은 위젯·세로 패널 각각 1~30개를 선택하며 즉시 적용·자동 저장됩니다. 화면 아래 뉴스는 목록 내부에서 스크롤합니다. 현재 피드에 뉴스가 적으면 그 수만큼 표시하고, 검색·유형 필터·핀을 적용한 결과 안에서 개수를 제한합니다. 표시 개수 변경은 수집·번역 API를 추가 호출하지 않습니다.

- **왼쪽 시계 · 오른쪽 시계:** 각각 원하는 시간대를 선택합니다. 기본값은 한국(`Asia/Seoul`)과 뉴욕(`America/New_York`)이며, 주요 도시와 브라우저가 지원하는 다른 시간대를 고를 수 있습니다. 같은 시간대를 양쪽에 선택할 수도 있습니다.
- **기본 시간대 복원:** 왼쪽 한국·오른쪽 뉴욕으로 돌아갑니다. 테마와 색상은 유지합니다.

- **미드나이트 · 차콜 · 포레스트 · 라이트:** 네 가지 기본 테마를 즉시 적용합니다.
- **배경색 · 포인트색:** 색상 선택기로 직접 지정합니다. 카드·탭·시계·설정 창이 함께 변경되고 글자·상태·뉴스 배지 색은 대비를 유지하도록 조정됩니다.
- **기본 테마 복원:** 미드나이트로 돌아갑니다. 고정 기사와 다른 읽기 설정은 유지합니다.
- **완료 / × / Esc:** 설정 창을 닫습니다. 변경 사항은 자동 저장되므로 별도의 적용 버튼이나 서버 재시작이 필요 없습니다.

표시 개수는 이 브라우저의 `news-overlay-widget.reader.limit.widget`·`news-overlay-widget.reader.limit.panel`, 시간대는 `news-overlay-widget.clocks.v1`, 테마·색상은 `news-overlay-widget.appearance.v1` 항목에 따로 저장됩니다. 같은 브라우저 프로필에서 **같은 주소·포트**로 열린 위젯·패널 창에 즉시 동기화되고 새로고침 후에도 유지됩니다. 다른 브라우저·프로필이나 OBS의 독립 브라우저 소스에는 각각 설정해야 합니다. 저장소 사용이 차단된 환경에서는 현재 창에 적용하고 저장 불가 상태를 표시합니다. 시간대·테마 변경은 뉴스 API를 호출하지 않습니다.

### 시장 시세 전광판

위젯·패널의 두 시계 바로 아래에 [TradingView Ticker Tape](https://www.tradingview.com/widget-docs/widgets/tickers/ticker-tape/)를 표시합니다. 시계와 한 카드로 묶고 배경을 테마에 맞춰 자연스럽게 연결합니다. 가격·등락액·등락률이 한 줄로 흐르고 TradingView에서 자동 갱신합니다. 작은 위젯에서는 시세 글자와 줄 높이를 패널의 80%로 표시하며, 뉴스 글자 크기 설정은 별도로 유지됩니다. 항목을 누르면 해당 종목 페이지가 열립니다.

| 표시 | TradingView 심볼 | 기준 |
|---|---|---|
| 나스닥100 CFD | `FOREXCOM:NAS100` | FOREX.com의 US 100 Cash CFD. 나스닥 종합지수와 다른 상품 |
| 달러/원 | `FX_IDC:USDKRW` | 1달러당 원화 |
| 유로/원 | `FX_IDC:EURKRW` | 1유로당 원화 |
| 비트코인/USD | `BITSTAMP:BTCUSD` | Bitstamp의 달러 가격 |

나스닥 종합지수(`NASDAQ:IXIC`)는 실제 확인 시 외부 위젯에서 가격 제공이 제한되어 사용자가 선택한 나스닥100 CFD로 구성했습니다. [TradingView의 데이터 정책](https://www.tradingview.com/widget-docs/faq/data/)에 따라 종목별 지연·제공 제한이 있을 수 있으며 해당 표시와 출처 링크를 유지합니다.

기존 밝은/어두운 테마에 맞춰 전광판도 전환됩니다. 뉴스 탭·위젯/패널 전환은 시세 연결을 다시 만들지 않습니다. 시세를 불러오지 못하면 **다시 연결**을 표시하며 뉴스와 시계는 계속 동작합니다. 브라우저가 TradingView에 직접 연결하므로 별도 API 키가 필요 없고 Massive·DeepL 호출도 추가하지 않습니다.

`js/config.js`의 `marketTicker.symbols`에서 종목을 바꾸거나 `marketTicker.enabled=false`로 숨길 수 있습니다. 이번 변경은 전용 서버의 자산 경로도 추가하므로 이미 실행 중인 이전 서버는 한 번 재시작해야 합니다.

### 현재 시각과 뉴스 분류

두 화면 모두 상단에 선택한 **왼쪽·오른쪽 시간대**의 도시 이름·날짜·현재 시각을 표시합니다. 기본값은 **한국(KST)**과 **뉴욕(EST/EDT)**입니다. 서머타임과 날짜 차이는 해당 지역 기준으로 자동 적용되며, 시계의 초 갱신은 뉴스 API 요청과 무관합니다.

기사 제목 아래에는 원래 발행 시각을 선택한 두 시간대 순서로 함께 표시합니다. 기사 메타 정보의 절대 시각과 하단 수집·갱신 시각은 왼쪽 시계 기준이며, 하단 오른쪽에 기준 도시를 표시합니다. 읽기 고정 중에도 시간대 변경이 반영됩니다. 날짜만 제공된 기사는 '시각 미제공'으로 표시하며, 수신·수정 시각을 발행 시각으로 바꾸지 않습니다.

`모든 유형` 메뉴에서 유형별로 모아 볼 수 있습니다. 분류 배지에 마우스를 올리면 기준을 확인할 수 있습니다.

| 표시 | 기준 |
|---|---|
| 속보 | 공급자의 Breaking / Breaking News / Urgent 채널·태그 또는 원문 제목 앞의 명시적인 속보 표식 |
| 주요 기사 | 공급자의 Hot / Top Stories 분류 |
| 기보도 | 원문 제목 앞에 Reported Earlier 등 이전 보도 표식이 있음 |
| 경제지표 · 실적·전망 · 투자의견 · 분석·의견 | 공급자의 해당 채널·태그 |
| 공식 발표 · 기업 보도자료 | 공식 발표 피드 또는 보도자료 출처·분류 |
| 일반 뉴스 | 별도 유형 표식이 없는 기사 |

[Massive News API](https://massive.com/docs/rest/partners/benzinga/news)는 채널·태그·원발행·최종 갱신 시각을 제공하지만 모든 기사에 공통인 속보 여부 필드는 명시하지 않습니다. 따라서 최근 도착했거나 제목이 짧다는 이유만으로 속보로 추정하지 않습니다. '속보' 필터가 비어 있어도 '모든 유형'에는 최신 뉴스가 있을 수 있습니다. '최근 5분'은 발행 시각에 따른 표시로 뉴스 유형과 별개입니다.

`포트 8787가 이미 사용 중입니다`가 나오면 기존 위젯이 실행 중인지 위 주소를 먼저 열어 확인하세요. 실행기는 포트 충돌 시 추가 수집기를 시작하지 않습니다. 수집기 실행 옵션을 바꾸려면 기존 실행 터미널에서 Ctrl+C로 종료한 뒤 다시 실행합니다. `로컬 화면 발행: 1초`는 화면 데이터 취합 주기이며 Massive API 조회는 기본 10초 간격입니다.

## 수집과 화면 반영

| 단계 | 기본 동작 |
|---|---|
| Massive → Benzinga | 최신 200건을 기본 10초 간격 REST 조회. 인증은 Authorization 헤더 |
| Marketaux | 목표 15초, 최대 50개 요청. 실제 응답의 일일·분당 한도로 자동 감속 |
| 연준·BLS·BEA | 기본 60초, 공급자 TTL 우선. BEA 관측 TTL 17분 |
| SEC·EIA | 기본 120~300초, 공식 보도자료/에너지 분석 |
| PR Newswire | 금융·기술·기업·에너지 4개 RSS, 기본 120초 |
| CNBC | 주요 뉴스·경제 2개 RSS. TTL 60분 준수, 보완 기사 용도 |
| Reuters | 45초, 401/403 차단 시 최소 1시간 대기 |
| Benzinga 직접 스트림 | Massive를 사용하지 않고 직접 발급 키가 있을 때 WebSocket 연결 |
| 로컬 발행 | 1초 간격으로 소스별 완료 결과 취합 |
| 번역 | 원문을 먼저 표시하고 새 제목을 건별 비동기 번역. 캐시 재사용 |
| 브라우저 | SSE 변경 알림, 실패 시 5초 간격 로컬 JSON 조회 |

화면 갱신은 뉴스 API를 호출하지 않습니다. 느린 소스나 번역이 다른 소스의 수집을 막지 않습니다. 로컬 발행과 SSE 확인 주기 때문에 수신 후에도 약간의 지연은 있으며, 공급자 수집 지연과 OBS/유튜브 송출 지연은 별도입니다.

Marketaux 응답이 Standard의 `daily_limit=10000`이면 15초 목표를 사용합니다. 24시간 운영 시 정상 요청은 최대 약 5,760회입니다. 무료 한도 `100`이면 약 899초 이상으로 자동 감속합니다. 한도를 확인하지 못하면 무료 한도를 기준으로 동작합니다. 구독 변경은 다음 실제 API 응답부터 반영됩니다.

요청 예약과 성공 결과는 `data/.relay-cache/`에 저장합니다. 이 상태 디렉토리와 API 키를 쓰는 수집기는 하나만 실행하세요. 다른 프로그램의 같은 키 사용량도 계정 한도에 포함됩니다. Marketaux 일일 한도 소진은 보수적으로 24시간 대기합니다. Massive의 401/403은 최소 1시간, 429는 최소 60초 대기하고 공급자의 `Retry-After`가 더 길면 우선합니다.

## 번역 표기 검사

한국어 번역의 회사명·단어 안에 한자가 잘못 섞인 표기를 검사합니다. `美·中·株·比` 같은 뉴스 약자, 원문에 있는 한자, `반도체(半導體)`처럼 독립된 한자 표기는 그대로 유지합니다. 전체 번역의 정확성을 판정하는 기능은 아니며, 혼합 표기의 이상 여부를 검사합니다.

`트랜스디그姆`은 원문에 `TransDigm`이 있을 때만 원문 회사명으로 교정합니다. 그 외 의심 표기는 제목 전체를 원문으로 표시하고 `번역 확인 · 원문` 배지를 붙입니다. 새 번역, 기존 캐시 재사용, 이전 정상 뉴스 유지, 브라우저의 고정 기사 복원에 같은 검사를 적용합니다.

검사 기준과 확인된 교정 규칙은 `translation-policy.json`에 있습니다. 수정하면 수집기·서버를 재시작합니다. 품질 검사에 걸린 번역은 해당 캐시 항목에 확인 필요 상태를 저장하여 DeepL 재호출을 반복하지 않습니다. 재번역이 필요하면 수집기를 정지한 뒤 해당 캐시 항목만 제거하고 다시 실행합니다. 정상 캐시를 일괄 삭제할 필요는 없습니다.

## 예상 영향 표시

`호재 예상`·`악재 예상`·`영향 혼재`는 기사 원문의 사건에서 추정한 단기 주식 영향입니다. 카드에 해당 종목 또는 `미국 증시`와 경제적 이유를 함께 표시합니다. 배지나 이유에 마우스를 올리면 판단에 사용한 원문을 확인할 수 있습니다. 실제 시세 반응, 선반영 여부나 통계적 예측 적중률을 검증한 결과는 아닙니다.

- 기업 실적은 전년 대비 증가보다 **예상치 대비 결과**를 봅니다. EPS·매출·전망이 서로 반대 방향이면 상쇄 점수를 내지 않고 `영향 혼재`로 표시합니다. 숫자와 예상치가 함께 있으면 단위·적자·전망 범위를 비교하며, 범위에 예상치가 포함되면 그 비교로는 방향을 붙이지 않습니다.
- 기업의 이익·매출 전망 변경, 자사주 매입 승인, 보통주 공모, 파산 신청, FDA 승인·거절, 투자의견 변경은 사건과 대상이 확인되는 범위에서 이익·수급·희석·상업화 경로를 표시합니다. 기업 사건은 단일 티커가 확인될 때만 판단하며, 경쟁사·복수 기업의 영향은 보류합니다.
- 미국 CPI/PCE는 예상 대비 서프라이즈를 금리·할인율 경로로 해석합니다. 연준의 실제 금리 결정도 구분하지만, 예상에 부합한다고 명시되면 방향을 보류하고 경기·금융 위기와 동반된 인하는 `영향 혼재`로 표시합니다. 미국 고용·GDP·소비 지표 서프라이즈는 성장과 금리 경로가 상충할 수 있어 혼재로 처리합니다.
- 할인 행사·홍보·실적 일정·주가 등락 단어만으로는 방향을 붙이지 않습니다. 가정·부인·예고·과거 회고, 대상 불명확, 지원하지 않는 사건도 표시를 생략합니다. 표시가 없다고 시장 영향이 없다는 뜻은 아닙니다.

판단은 `tools/market_impact.py`에서 처리하며 추가 유료 API 호출이 없습니다. 헤드라인이 판단의 출발점이고 요약의 반대 근거는 혼재·보류로 반영합니다. 공개 JSON의 `marketImpact`에 버전·대상·이유·근거를 저장합니다. 기존 수집 캐시와 장애 시 유지되는 뉴스도 다시 판단하며, 브라우저·고정 기사에서 과거 단어 점수만 있는 호재/악재 표시는 사용하지 않습니다. `js/config.js`의 `sentiment.enabled=false`로 예상 영향 표시를 끌 수 있습니다.

금리 경로의 참고 자료: [연준의 통화정책 전달 경로 설명](https://www.federalreserve.gov/monetarypolicy/monetary-policy-what-are-its-goals-how-does-it-work.htm). 개별 사건의 분류 규칙은 프로젝트의 보수적인 해석이며, 추가 사건을 지원하려면 규칙과 반례 테스트를 함께 확장합니다.

공식 발표 피드는 `tools/feed_sources.py`에 정의합니다.

| 피드 | 내용 |
|---|---|
| 연준 통화정책 | FOMC 성명·의사록 |
| 연준 연설·증언 | 연준 인사 발언 자료 |
| BLS CPI / 고용 / PPI / JOLTS | 소비자물가·비농업고용·실업률·생산자물가·구인/이직 발표별 RSS |
| BEA | GDP·PCE 관련 개인소득/지출·무역 등 |
| SEC | 규제 보도자료. 기업별 8-K/10-Q 공시 수집과는 별개 |
| EIA | 보도자료·Today in Energy 분석. 주간 원유재고 초단위 피드 아님 |

BLS는 여러 시점의 수치를 섞은 요약 대신 발표별 RSS를 사용합니다. 발표 시각을 현재 시각으로 바꾸지 않습니다. 공식 발표 탭은 최근 7일, 통합 탭은 최근 48시간을 보여 줍니다. 조용한 기간에는 연결이 정상이어도 표시할 발표가 없을 수 있습니다. RSS 자체의 업데이트 지연은 조회 간격만 줄여 해결할 수 없습니다.

공개 피드는 총 16개(공식 10개, 기사·보도자료 6개)입니다. 조건부 요청과 피드 TTL을 적용하고 `--rss-interval`을 낮춰도 공급자 권장 간격보다 자주 요청하지 않습니다. `--no-public-rss`로 CNBC/PR Newswire를 끌 수 있습니다. 기업 보도자료에는 별도 배지를 표시하며, 상투적인 위험 고지에만 경제 키워드가 있는 홍보성 자료는 제목 기준으로 제외합니다.

| Benzinga | `?tab=benzinga` | `data/news.benzinga.json` |

v1.0.0에서는 데이터가 없는 Reuters·Marketaux 탭을 제거했습니다. 이전에 해당 탭을 선택해 두었거나 이전 탭 URL로 접속하면 통합 탭이 열립니다. 필요할 때 단일 소스로 실행할 수 있도록 기존 수집 옵션은 유지합니다.

키가 없는 Benzinga 탭은 `소스 연결 설정 필요`를 표시합니다. 탭 선택과 핀은 브라우저에 저장하고 핀은 탭별로 분리합니다.

### 기사 한국어로 읽기

헤드라인·카드를 누르면 위젯 안에 **한국어 내용 창**이 열립니다. 외부 영어 페이지나 번역 사이트로 바로 이동하지 않습니다. 통합·Benzinga·공식 발표·기사·보도자료 탭, 작은 위젯·세로 패널, 고정 기사에 공통 적용됩니다.

- Benzinga: 처음 연 기사는 [Massive News API](https://massive.com/docs/rest/partners/benzinga/news)에서 발행 시각으로 조회한 뒤 **기사 ID가 정확히 일치하는 본문**만 사용합니다. 앞부분 최대 3개 문단·1,800자를 발췌해 기존 DeepL 키로 번역합니다. 문단·발언 주체·수치·부정 표현을 유지하도록 번역하며, 전체 기사에 대한 생성형 요약이 아닌 **본문 발췌 번역**임을 표시합니다.
- 본문이 없으면 **제공된 소개문 번역**, 소개문도 없으면 **제목만 제공된 뉴스**로 구분합니다. 다른 피드는 제공된 소개문 범위만 번역하며 임의의 기사 주소를 스크래핑하지 않습니다. 본문 조회 실패는 본문 미제공과 구분해 안내합니다.
- 아래에 **원문 보기**, 대응 기사가 확인된 경우에만 **한국어판 보기**를 표시합니다. `한국어판 검색`과 `articleLink.mode`에 따른 외부 번역 사이트 이동은 제거했습니다. 한국어판을 못 찾더라도 위젯의 한국어 번역은 별도로 제공됩니다.

한국어판 링크는 [Benzinga Korea 공개 RSS](https://kr.benzinga.com/feed/)의 제목·발행 시각·종목·숫자·방향 표현을 보수적으로 대조합니다. 한국어판 제목이 크게 달라지거나 후보가 모호하면 링크를 표시하지 않습니다. 한국어판이 늦게 게시되거나 아예 없는 뉴스도 있으며, 제목 기반 대조는 공식 기사 ID 매핑이 아닙니다. 영문 주소의 도메인이나 ID를 바꿔 한국어 주소를 만들지 않습니다. 링크에 마우스를 올리면 대조한 제목을 확인할 수 있습니다.

본문 조회·번역은 **사용자가 기사를 열 때만** 실행합니다. 동시 중복 요청을 합치고 결과를 `data/.relay-cache/article-summaries.ko.json`에 최대 300건 저장해 재열람·서버 재시작 때 재사용합니다. 기사 수정 시 새 내용을 번역합니다. 번역 API 오류는 대기 후 수동 재시도하며, 혼합 문자 검사에서 보류된 번역을 반복 결제하지 않습니다. 기존 `--translate-provider none` 설정을 존중합니다. 이미 읽은 고정 기사는 피드에서 사라져도 저장된 번역을 읽을 수 있고, 처음 여는 오래된 고정 기사는 내용이 없을 수 있습니다.

한국어판 링크 목록은 `data/.relay-cache/benzinga-korean-links.json`에 최근 7일·최대 500건의 메타데이터를 저장하며 RSS의 권장 갱신 주기를 따릅니다. 이 목록 조회는 유료 API를 호출하지 않습니다. 본문·번역 캐시와 키 파일은 HTTP 파일 제공 대상에서 제외하며, 번역 요청은 현재 피드 또는 서버에 저장된 기사만 허용합니다.

```bash
# 현재 Reuters 체험 종료 상태에서 Marketaux + 공식 피드로 운영
python3 tools/run_overlay.py --no-reuters-default-feed

# 실제 관측된 API 한도가 설정값보다 우선
python3 tools/run_overlay.py --marketaux-interval 15 --official-interval 60

# 단일 소스 / 통합 탭만 표시 / 표시 개수
python3 tools/run_overlay.py --provider marketaux
python3 tools/run_overlay.py --no-tabs --limit 8

# 공식 발표 보관 기간, 필터, 정렬
python3 tools/run_overlay.py --official-lookback-hours 336
python3 tools/run_overlay.py --min-overlay-score 3 --rank-mode balanced
python3 tools/run_overlay.py --countries us --use-preferred-domains

# 허가된 Reuters RSS/Atom/news sitemap 지정
python3 tools/run_overlay.py --reuters-feed 'https://YOUR_PROVIDER/authorized-feed.xml'

# 포트와 브라우저
python3 tools/run_overlay.py --port 8888 --open-browser
```

`--watch`는 로컬 발행 주기입니다. 이를 60초로 늘리면 15초 수집 목표도 달성할 수 없으므로 기본 1초를 권장합니다. `--rank-mode fresh`는 최신순, `balanced`는 최신성과 점수, `score`는 점수순입니다. `--min-overlay-score 0`은 관련성 필터를 해제합니다. Reuters를 강제로 포함하려면 `--min-reuters-items 1`을 사용합니다.

단일 실행은 다음과 같습니다. 지속적인 스트림과 비동기 번역은 watch 모드에서 동작합니다.

```bash
python3 tools/news_relay.py --provider combined --tab-feeds --translate-provider deepl
python3 tools/serve_overlay.py --port 8787
```

## Massive에서 구독한 Benzinga News 연결

Massive 대시보드 왼쪽 **Keys**의 API 키를 `keys/massive_api_key.txt`에 한 줄로 저장합니다. `MASSIVE_API_KEY` 환경변수나 `--massive-key-file /path/to/key.txt`도 지원합니다. 명시한 파일이 있으면 환경변수보다 우선합니다. 키는 서버에서만 읽고 요청 URL·브라우저 설정·뉴스 JSON에 넣지 않습니다.

`./run_massive.sh`를 실행하면 Marketaux와 만료된 Reuters를 제외한 통합 위젯이 실행됩니다. Massive 키를 자동으로 감지하여 **Benzinga 탭**과 **통합 탭**에 표시합니다. 이 REST 연결에는 WebSocket 패키지 설치가 필요 없습니다. Massive 키와 Benzinga 직접 키가 모두 있으면 Massive를 우선합니다.

```bash
# 기본 10초에서 15초로 조정
./run_massive.sh --massive-interval 15

# Massive 뉴스만 표시
python3 tools/run_overlay.py --provider massive --limit 30
```

최근 48시간 범위에서 최신 200건을 다시 조회하여 원래 발행 시각과 수정 시각을 구분합니다. `--massive-fetch-limit`으로 1~1000건 범위를 설정할 수 있습니다. 재시작 시에도 최근 기사를 복구하지만, 장시간 중단이나 많은 뉴스 발생으로 이 범위를 벗어난 기사까지 모두 보충하는 전체 아카이브 수집은 아닙니다. API 최신 목록에서 삭제되거나 범위를 벗어난 기사는 다음 정상 결과에 반영됩니다. 새 제목은 원문을 먼저 표시하고 한국어 번역이 끝나는 대로 교체합니다.

2026-11-10 실제 사용자 구독 키로 HTTP 200/OK, 기사 수신과 한국어 번역을 확인했습니다. 공식 [News v2 문서](https://massive.com/docs/rest/partners/benzinga/news), [헤더 인증 안내](https://massive.com/docs/rest/quickstart)를 따릅니다.

## Benzinga 직접 발급 키로 연결하는 경우

실시간 뉴스 스트림 권한이 있는 API 키를 준비하고 선택 의존성을 설치합니다.

```bash
python3 -m pip install -r requirements-stream.txt
```

`keys/benzinga_token.txt`에 키를 저장하고 위젯을 재시작합니다. `BENZINGA_API_KEY` 환경변수 또는 `--benzinga-key-file /path/to/token.txt`도 지원합니다. `--no-benzinga`로 끌 수 있습니다. 키를 브라우저 설정이나 URL에 넣지 마세요.

이 직접 스트림 연결은 새 기사/수정/삭제 이벤트를 처리합니다. 기사 ID로 중복을 제거하고 원래 발행 시각을 유지합니다. heartbeat와 재연결 대기를 구현했습니다. 직접 스트림에는 시작 전/중단 동안의 REST 보충 수집이 없습니다. 직접 발급 키가 없어 스트림 연결은 검증하지 못했으며, 이벤트 파싱·수정·삭제는 모의 데이터로 검증했습니다. 위 Massive REST 연결과는 별개입니다.

현재는 진행자 전용 열람이므로 방송 재배포 계약을 전제로 하지 않습니다. 일반 웹 서비스 구독과 API/자동 수집 권한은 구분합니다. 향후 위젯 화면을 공개 송출한다면 그 이용 범위는 별도 확인해야 합니다. [뉴스 소스 비교와 세이브티커 조사](NEWS_SOURCES.md)를 참고하세요.

2026-11-10 사용자 확인 기준 Reuters는 체험 종료로 현재 사용 불가입니다. 위의 `--no-reuters-default-feed` 실행 옵션으로 제외할 수 있습니다. Marketaux는 무료 한도가 관측된 상태입니다.

## 상태와 파일 보호

- 소스 실패 시 마지막 성공 데이터와 원래 시각을 보존하고 실패 상태 표시
- `번역 중`: 원문 우선 표시. 실패 시 `원문`과 번역 오류 상태 표시
- `뉴스 갱신 지연`: 수집기 heartbeat 정지. `최신 기사 지연`: 기사 자체가 오래됨
- 공식 발표 탭은 발표가 드문 특성을 반영해 설정된 보관 기간을 오래됨 기준으로 사용
- 피드·상태·번역 캐시는 임시 파일 작성 후 원자적으로 교체
- 전용 서버는 위젯 자산, 지정한 여섯 JSON, 그 JSON의 SSE 알림만 제공. 키·환경 파일·캐시·코드·디렉토리 목록은 비공개

`--out`, `--marketaux-out`, `--reuters-out`, `--official-out`, `--rss-out`, `--benzinga-out`으로 저장 위치를 바꿔도 로컬 제공 URL은 유지됩니다. `?url=...` 또는 `?source=...`는 탭을 끄고 지정 소스를 사용합니다. 임의 로컬 파일은 제공되지 않으므로 커스텀 JSON은 `--out`으로 연결하세요.

## 검증

외부 API 없는 회귀 테스트입니다. Node.js 18 이상과 localhost 임시 포트가 필요합니다.

```bash
python3 -m unittest discover -s tests -v
node tests/frontend.test.cjs
```

API 한도 변경, 재시작·오류 대기, RSS 조건부 요청, 공식 발표 시각/보관 구간, 독립 수집, 번역 캐시, 스트림 수정/삭제, SSE 경로 보호, 탭 전환과 원문→번역 반영을 검증합니다. 화면 테스트는 DOM 모의 환경이며 실제 OBS 레이아웃 검증은 별도입니다.
